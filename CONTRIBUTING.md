# Contributing

Thanks for helping improve this Git and interview-prep resource.

## Ways to contribute

- Add a useful Git command or practical example.
- Improve an explanation for clarity or correctness.
- Add an interview question with a concise answer.
- Fix typos, formatting, or outdated guidance.

## Pull request guidelines

1. Keep each pull request focused on one improvement.
2. Prefer practical examples over generic definitions.
3. Verify commands before submitting them.
4. Use clear commit messages.
5. Update the README when adding a new topic.

## Content quality

Please avoid copying material from books, courses, or other repositories without permission. Contributions should be original or properly attributed.
