# Git Learning Path

Use this path to move from basic Git usage to interview-ready knowledge.

## Beginner

Learn: `git init`, `git clone`, `git status`, `git add`, `git commit`, `git log`, `git push`, and `git pull`.

**Goal:** create a repository, make commits, connect a remote, and publish changes.

## Intermediate

Learn branches, `git switch`, `git merge`, `git fetch`, pull requests, merge conflicts, `git stash`, and `git restore`.

**Goal:** work safely on a feature branch and collaborate with others.

## Advanced

Learn `git rebase`, `git rebase -i`, `git reset`, `git revert`, reflog, cherry-pick, bisect, tags, and release workflows.

**Goal:** diagnose history problems and maintain a clean, understandable project history.

## Interview checkpoint

You should be able to explain, with examples:

1. fetch vs pull
2. merge vs rebase
3. reset vs revert
4. working tree vs staging area vs repository
5. local branch vs remote-tracking branch
6. HEAD and refs
7. how to recover from a bad local commit
8. how to resolve a merge conflict
9. when rewriting history is safe
10. why destructive commands require extra care

Then use the interview material in `GIT Theory & Interview Questions.docx` for deeper revision.
