# Git Command Reference

## Repository & setup

git init  -->  Initialize a new local Git repository.

git clone  -->  Create a working copy of an existing repository.

git config  -->  Read or set Git configuration values.

git remote  -->  Manage remote repository connections such as origin.

## Everyday workflow

git status  -->  Show the state of the working tree and staging area.

git add  -->  Stage changes for the next commit.

git commit  -->  Create a new commit from the staged snapshot.

git push  -->  Send local commits to a remote repository.

git fetch  -->  Download remote refs and objects without integrating them into the current branch.

git pull  -->  Fetch remote changes and integrate them into the current branch. The integration may use a merge or rebase depending on configuration and options.

## Branching & integration

git branch  -->  Create, list, rename, or delete branches.

git checkout  -->  Switch branches or restore files; for modern Git, prefer git switch for branch changes and git restore for file restoration when possible.

git merge  -->  Integrate the histories of two branches.

git rebase  -->  Replay commits onto a new base, often producing a more linear project history.

git rebase -i  -->  Interactively reorder, edit, squash, or drop commits. Use carefully on branches already shared with others.

## History & recovery

git log  -->  Inspect commit history and explore previous revisions.

git reset  -->  Move HEAD and optionally change the index and working tree. Be especially careful with --hard because it can discard local changes.

git revert  -->  Create a new commit that reverses the effect of an earlier commit. This is generally safer for shared history.

git clean  -->  Remove untracked files and directories. Preview with git clean -n before using deletion flags.

## Stash

git stash  -->  Temporarily save local modifications so the working tree can be cleaned up.

git stash pop  -->  Reapply the most recent stash and remove it from the stash list.

git stash apply  -->  Reapply a stash while keeping the stash entry.

## Safety reminders

Before a destructive or history-rewriting operation:

git status
git log --oneline -n 10
git branch backup-before-change

Prefer testing destructive commands in a disposable branch or repository when learning.
